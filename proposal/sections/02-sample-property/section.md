## Sample property and site character

This proposal uses the prior listing for **Tbd Rider Hollow Road, Hardenburgh, NY 12406** as a feasibility example, not as a currently verified acquisition target.

| Attribute | Prior-proposal record |
|---|---|
| Approximate acreage | 15.7-16 wooded acres |
| Map pin | 42.102681, -74.523254 |
| Listing reference | Zillow property ID 32842779 |
| Prior asking price | $189,000; the legacy budget used a fixed $200,000 land allowance |
| Reported improvements | Driveway, leveled/excavated areas, engineered septic, and electric availability |
| Site character | Secluded woodland, rugged surrounding terrain, usable clearings, trails, and a seasonal stream |

The attributes are promising because existing access, a disturbed clearing, power, and an approved septic system can reduce early site-development cost. None should be relied on without documentary verification. In particular, obtain the septic permit and approved design flow, survey and easements, utility confirmation, potable-water feasibility, and current listing/title information.

The seasonal stream and mountain terrain make the site a useful stress test for Hardenburgh’s natural-resource rules. Acreage alone does not establish a buildable envelope.
