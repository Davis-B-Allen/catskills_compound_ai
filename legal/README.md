# Legal and regulatory research

This directory separates evidence from interpretation:

- `sources/` contains archived official documents and clearly labeled reference links.
- `analysis/` contains dated, project-specific planning analysis generated from those sources.

Start with [the source catalog](sources/SOURCE_CATALOG.md), then read the analysis in numeric order. The analysis is an issue-spotting aid, not legal advice, an approval, or a substitute for the Town of Hardenburgh Code Enforcement Officer, Planning Board, Ulster County, New York State, or licensed professionals.

Before relying on any conclusion, confirm that the archived authority is still current and that it applies to the actual tax parcel, proposed occupancy, water/septic design, and construction date.
