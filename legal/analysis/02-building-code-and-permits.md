# Building-code and permit analysis

**Analysis date:** August 23, 2026  
**Status:** Planning issue-spotting; code edition and classification must be confirmed for each permit.

## Current code baseline

The New York Department of State states that the 2025 Uniform Code and 2025 Energy Conservation Construction Code became fully effective on December 31, 2025. The archived 2025 Residential Code of New York State is therefore the current planning baseline, not the project-supplied generic 2021 IRC page and not the 2020 code named in Hardenburgh’s 2024 permit packet.

## Permits and the 144-square-foot misconception

Section R105.1 of the 2025 Residential Code requires a permit before work that must conform to the Uniform or Energy Code. Section R105.2 allows only those exemptions that the local code-enforcement program adopts and Part 1203 permits.

Part 1203 allows a local program to exempt one-story detached structures of no more than 144 square feet only when associated with qualifying dwellings and used for tool/storage sheds, playhouses, or similar uses (19 NYCRR §1203.3(a)(1)(i), PDF p. 5). An exemption is optional and never authorizes a code or zoning violation.

**Project application:** the proposed guest cabin is 192 square feet and intended for sleeping, so it does not fit the cited size or use language. It should be designed and presented as permitted occupied construction, not as a shed workaround.

## “Tiny house” terminology

Appendix BB of the 2025 Residential Code defines a tiny house as a dwelling of 400 square feet or less, excluding lofts, and applies to tiny houses used as single dwelling units (Appendix BB, §§BB101-BB102, printed p. 857).

- The 480-square-foot principal home is not a code-defined tiny house.
- The 440-square-foot ADU is not a code-defined tiny house.
- A 192-square-foot guest structure is small enough dimensionally, but Appendix BB applies only if it is classified and designed as a single dwelling unit; the current no-kitchen accessory-sleeping concept creates a different classification question.

Use “compact home” in approval conversations unless the specific code-defined tiny-house path is intended.

## Life safety and water features

Occupied sleeping spaces must be reviewed for the current code’s smoke alarm, carbon-monoxide alarm, and emergency escape/rescue requirements (2025 RCNYS §§R310, R311, and R319). Sauna, solid-fuel equipment, gas cooking, guards, stairs, decks, and interconnected structures each add discipline-specific requirements.

The 2025 code defines a swimming pool broadly to include a basin capable of holding water more than 24 inches deep, including hot tubs, spas, and wading pools (§R328.2). Section R328 addresses design standards, barriers, alarms, and safety-cover alternatives. **Project inference:** record the designed water depth and product listing for both the cold plunge and wood-fired hot tub, then obtain code-official review before fixing deck geometry around them.

## Local permit packet

Hardenburgh’s 2024 packet requests, among other items, a complete application, fee, workers’ compensation/disability evidence, septic approval when needed, plot plan, flood-zone permit when needed, and two sets of plans/specifications for site-built dwellings and accessory buildings. It says a certificate of occupancy or compliance is required before occupancy. Because the packet names the superseded 2020 code and contains setback numbers that differ from the zoning law, request a current checklist directly from the Town.
